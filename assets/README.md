# Assets

This directory is the root for runtime assets.

- `models/` is reserved for aircraft, projectiles, and environment models.
- `materials/` is reserved for future shared material definitions or texture atlases.
- `audio/` is reserved for engine, gunfire, and UI sounds.

The current aircraft prototype is still generated procedurally in code, but future GLTF or mesh assets should be placed here instead of being embedded in Rust source.
